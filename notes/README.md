# Заметки по дизайну

Каждый новый экспорт макетов (zip с SVG-фреймами 390×844 из Figma) сравнивается
с предыдущим поэлементно, и изменения записываются сюда по экранам.

- `screens.md`: какой файл экспорта какой экран и где он в коде.
- `changes/<дата>-<экспорт>.md`: изменения по страницам, вручную, по-русски.
- `changes/<дата>-<экспорт>.raw.md`: полный машинный отчёт, вплоть до атрибутов.
- `snapshots/latest.json.gz`: снимок последнего экспорта. Это база для следующего сравнения,
  старый zip хранить не нужно.
- `tools/svgdiff.py`, `tools/compare.sh`: сам инструмент.

## Как сравнить новый экспорт

```bash
notes/tools/compare.sh ~/Downloads/"AutoLayouts BG(3).zip" 2026-10-20-BG3
```

Если в zip только часть экранов, добавь `--partial`: тогда новые экраны заменят в базе свои старые
версии, а остальные останутся.

Скрипт печатает таблицу экранов, где что-то поменялось. Детали лежат в `.raw.md`, его читаем
кусками по нужному экрану (`awk '/^## Имя/,/^## /'`), а не целиком.

## Почему так дёшево

- SVG весят до 20 МБ, почти всё в них картинки base64. В снимке от картинки остаётся хеш, размер
  и имя файла, от `d` у path остаются bbox и хеш. Весь экспорт сжимается примерно до 150 КБ.
- Числа округлены до 0.1, сдвиги до 0.6px не считаются. Номера, которые Figma генерирует заново
  (`clip0_4449_3514`, `pattern4`, `Frame 1397`, `Vector_2`), отбрасываются. Без этого в diff был бы
  один шум.
- Экраны сопоставляются по содержимому (набору имён слоёв), а не по имени файла: Figma
  перенумеровывает `-1/-2/...` при каждом экспорте.
- Слои внутри экрана сопоставляются по имени и тегу, а среди одноимённых (Vector, Ellipse) по
  ближайшей позиции. Поэтому перегруппировка автолейаутов не выглядит как «всё удалено и добавлено».
- Одинаковые изменения на многих слоях (клавиши клавиатуры, строки списка) сворачиваются в одну строку.
- Текст в экспорте переведён в кривые, но имя слоя и есть текст. Размер шрифта виден только по
  bbox, точный кегль подбирается отдельно при переносе.

# Студенческое приложение для Coventry University Kazakhstan (2026-10-23)

Идеи с Аишей. Приложение для студентов одного университета: начинаем с CUK, потом можно другие вузы.
Вход только по университетской почте, внутри только свои.

## Главные разделы

### 1. «Голос»: заявки о проблемах (делаем первым)
Студент сообщает о проблеме, остальные голосуют «меня тоже касается», у заявки виден статус и сколько дней она висит.

- Заявка: заголовок, категория, текст, фото, место (корпус / этаж).
- Голос «меня тоже» (одна кнопка, счётчик). Похожие заявки предлагаются при создании, дубли склеиваются.
- Статусы: новая → передана → в работе → решена / отказ (с причиной). Каждая смена статуса — уведомление
  всем, кто голосовал.
- Ответ от студсовета или администрации прямо в заявке (отмечен значком «официально»).
- Лента: «горячие» (по голосам за неделю), «новые», «решённые», фильтр по категориям.
- Анонимная подача (имя видит только модератор).
- Публичная статистика: сколько решено за месяц, среднее время ответа.

Категории и примеры из первого списка:
- **Инфраструктура:** дверца туалета на 3 этаже, мало мусорок в женских туалетах, мало розеток в классах,
  холодно на 1 этаже, мало подушек на диване, мебель не стирают, куртки путают и забирают (гардероб),
  спортзал закрывают.
- **Еда и цены:** кафетерий дорогой (всё по 900 ₸, хотя бы акции), вендинговые автоматы дорогие.
- **Учёба:** плохо составленное расписание, нельзя выбрать преподавателя (first come, first served; лимит
  20–25 человек в 2026, сейчас 50), забрали стипендию, приложение Spec-on.
- **Порядок:** пахнет айкосом, громкий хоккей, нужна «бесшумная» техника, маленький кампус.
- **Дорога:** пробки от и до университета (Коргалжынское шоссе), стиль вождения на парковке, дорожку
  долго чистят.
- **Администрация:** не отвечает, нет денег на студенческие проекты.

### 2. «Гид»: справочник первокурсника
- FAQ, вся информация и ссылки в одном месте, поиск по ключевым словам.
- AI-помощник отвечает только по базе университета (справки, пересдачи, кому писать) и даёт ссылку
  на источник. Claude API + документы университета.
- Частые вопросы из «Голоса» и «Гида» подсказывают, какие статьи дописать.

### 3. «События»: то, чем должен был стать Moodle
- Календарь мероприятий: клубы, конкурсы (Cosplay contest, Scream Queen), турниры, хакатоны.
- «Пойду», напоминание, сторис с мероприятия, фото после.
- Организаторы (клубы, студсовет) публикуют сами.

## Кто может помочь в университете
- Президент студсовета (подруга, помогал с кампанией): статусы и ответы на заявки, первые пользователи.
- Manju, Student Services: официальные ответы, материалы для «Гида».
- Мирас, президент университета: поддержка сверху, хакатон.

План запуска: пилот с одним курсом или студсоветом → студсовет отвечает на заявки → показать Student
Services статистику (что решается и как быстро) → официальный канал.

## Что берём из старого приложения (Smarts / Thoughts)

Почти весь бэкенд и большая часть экранов подходят. Новое: заявки, справочник, события, вход по
университетской почте.

| Было | Становится |
| --- | --- |
| Регистрация, вход, профили, подписки | То же + вход по почте `@coventry...` (подтверждение почты на бэкенде уже есть) + факультет и курс в профиле |
| Посты-статьи с обложкой, публикация с карточкой «Posting...» | Заявки «Голоса» (фото, текст) и статьи «Гида» |
| Лайки (общее состояние, отправка с задержкой) | Голос «меня тоже» |
| Комментарии (шторка) | Обсуждение заявки, ответ студсовета |
| Уведомления + точка на колокольчике | «Статус вашей заявки изменился», «новое событие» |
| Push-сервис и device tokens на бэкенде | Push о статусах и напоминания о событиях |
| Лента с ранжированием и вкладками | «Горячие / новые / решённые», вкладки по категориям |
| Сторис и ответы на них | Сторис с мероприятий, клубов |
| Чаты, фото в чатах, отправка поста карточкой | Чаты групп и клубов, «скинуть заявку другу» |
| Жалобы, блокировки, очередь модерации, роли USER / MODERATOR / ADMIN | Модерация заявок и комментариев; роль «студсовет» / «официально» |
| Админ-панель (`/admin`: статистика, пользователи, роли) | Панель студсовета: заявки, статусы, ответы, статистика |
| Поиск (`/search`), AI-эмбеддинги (семантический поиск) | Поиск похожих заявок (против дублей) и база для AI-«Гида» |
| Спам-скоринг | Защита «Голоса» от накруток |
| Контакты из телефонной книжки | «Кто из твоих одногруппников уже здесь» |
| Обрезка фото, анимации, шторки, меню ⋯ | Как есть |
| Сервер, Caddy, деплой, бэкапы, dev-сборки EAS, логи ошибок с телефона | Как есть |
| Tweak (правка отступов и цветов дизайнером) | Как есть, после закрытия старого доступа |

Чего лучше не тащить: моковые данные и демо-аккаунты, бренд и дизайн Thoughts (выяснить, чьи они;
безопаснее новое имя и свой вид), книги / полки (уже выключены).

## Первые шаги
1. Закрыть старые доступы (Tweak `alimkhan`, deploy key в GitHub), проверить, на ком аккаунты Expo /
   Figma / домен.
2. Новое имя и простой собственный стиль (без макетов Thoughts).
3. Вход по университетской почте (код на почту), факультет и курс.
4. «Голос»: модель заявки, статусы, голоса, лента, создание заявки, панель студсовета.
5. Показать президенту студсовета, завести первые 20–30 заявок из этого списка.

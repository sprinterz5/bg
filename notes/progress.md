# Перенос BG(2) и сверка приложения с макетом (2026-10-19)

Как сверяем: `notes/tools/uicheck.sh <папка экспорта> <кадр.svg> <маршрут>`. Приложение снимается в web
(режим `?capture`: iPhone 390×844, отступы 47/34, мок-пользователь, мок-чаты), для каждого слоя макета
считается сдвиг, а шрифт текста подбирается по пикселям (`textmatch.py`) и сравнивается со шрифтом в DOM.
Оценке «size×» для мелкого текста не верить: она шумит, смотреть строки FONT и картинку `*.side.png`.

## Сделано
- Регистрация без почты: Welcome → имя → username → пароль → повтор → аватар → интересы
  (бэкенд: email необязателен, пароль 6+ с буквой; **бэкенд не задеплоен**).
- Сверены и поправлены (расхождения ≤ 1–2pt):
  Welcome, имя, username, пароль, повтор, аватар, интересы, Home (новая лента), уведомления, Explore,
  поиск (ввод с профилями, результаты), Create, New Article (переделан под новый кадр), чаты, поиск в чатах,
  переписка, свой профиль (пустой), чужой профиль, Followers, Edit profile, Edit bio, Choose a cover,
  New story, превью поста, поиск в чатах (результаты и «ничего не найдено»), «username занят»,
  страница текста поста (шапка, карточка автора, нижняя панель), share sheet (геометрия; без данных о подписках).

## Не сверено
- Просмотр сторис: в web окно остаётся прозрачным (анимация появления не доходит до конца), проверять на телефоне.
- AutoLayouted-23: список чатов нового аккаунта с приветствием от «Thoughts» (1 непрочитанное). Такого
  сообщения бэкенд не присылает; нужен ли приветственный чат от системного аккаунта, решить отдельно.
- AutoLayouted-11 (свои Following): в кадре кнопки только у первых двух строк, оставлены у всех.

## Расхождения внутри макета (решено так)
- Варианты «No layout» и «AutoLayouted» одних экранов регистрации расходятся на 4–8pt: взяты AutoLayouted.
- Таббар: в кадрах профиля / Edit profile («The ORIG. toolbar») другие иконки (+, чат), чем на Home, Explore,
  чатах (самолётик, карандаш). Оставлен вариант Home.
- Текст кнопки Continue на интересах в кадре смещён на 8pt от центра, Share / Edit profile на 2–4pt: оставлено по центру.
- «active now» с зелёной точкой в чатах: у бэкенда нет данных о присутствии, не сделано.
